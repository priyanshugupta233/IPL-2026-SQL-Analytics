# 🏏 IPL 2026 SQL Analytics Project

## 📌 Project Overview

This project analyzes IPL 2026 data using SQL, Python, Pandas, SQLite, and Matplotlib.

The objective is to demonstrate SQL querying skills, data analysis techniques, and data visualization by exploring team performance, player statistics, batting records, bowling records, and match outcomes.

The project simulates a real-world Data Analyst workflow:

* Database Design
* Data Generation & Storage
* SQL Analysis
* Advanced SQL Queries
* Data Visualization
* Business Insights
